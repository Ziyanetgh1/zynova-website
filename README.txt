ZyNova Technologies one-page website

Files: index.html, styles.css, assets/

Publishing on GitHub Pages:
1. Create a new public GitHub repository for the public website (do not use the private portal repository).
2. Upload all files and the assets folder to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, main, / (root).
4. First confirm the GitHub Pages URL works.
5. Add custom domain www.ziyanet.ae in Pages settings.
6. At the DNS provider, create a CNAME record for www pointing to YOUR_GITHUB_USERNAME.github.io (replace placeholder with your actual GitHub username).
7. Configure the apex ziyanet.ae separately if desired; do not change the portal.ziyanet.ae DNS record.
8. Enable Enforce HTTPS when GitHub Pages makes it available.

IMPORTANT: The Enquire button currently uses info@ziyanet.ae as a PLACEHOLDER address. Update it to a verified, monitored address before publishing or remove the button.
